Sunlight is a Roblox executor for iOS and macOS. It's currently very early in development and doesn't have a full environment surface or offset dumper.

Most of the code in this project was written by LLMs guided by a human. It's not slop, but it's not as good as artisanal style would've achieved.

You can skid this of course, but [contributions](CONTRIBUTING.md) are preferred.
